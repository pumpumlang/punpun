# Speedrun rules status

PunBrain is a new standalone calculator executable. Its source may reproduce the same class of calculation as Ninjabrain Bot, but speedrun legality is based on the rules and approved tool/build lists, not merely on mathematical similarity.

The Minecraft Java Edition Speedrunning rules v7 reviewed during development explicitly named particular approved tools/builds, including Ninjabrain Bot up to the version stated in that ruleset. That approval does not automatically transfer to a newly compiled PunBrain executable.

Therefore:

- Do not describe PunBrain as officially MCSR-approved unless the moderators explicitly approve the PunBrain build/version.
- The standalone calculator is suitable for practice, development, algorithm comparison, and non-submitted play.
- Before using PunBrain in a submitted run, check the current rules and obtain whatever approval/listing the current rules require.
- Keep the source public when requesting review so moderators can inspect what data the tool uses and what it computes.

PunBrain's default standalone workflow reads the text Minecraft intentionally puts on the clipboard when the player presses `F3+C`. It does not require a Minecraft mod or inspect process memory. Whether that exact workflow is acceptable for a submitted run is still a moderation/rules question for this new tool.
