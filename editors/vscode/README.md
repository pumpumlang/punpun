# PunPun for Visual Studio Code

Official `.pp` language support for PunPun 0.9 development (compatible with the 0.6+ language-foundation line). The extension uses the compiler-backed language server rather than maintaining a second, approximate parser inside the editor.

## Features

- live compiler diagnostics with source ranges;
- semantic completion for language constructs, local/project symbols, members, built-ins and standard-library APIs;
- hover information, signature help and inlay hints;
- go to definition, references, document/workspace symbols and token-aware rename;
- semantic highlighting and `.pp` light/dark file icons generated from the canonical PP brand;
- compiler-backed formatting and quick fixes;
- build, run, check, test and Windows-target commands from the command palette.

## Install from a PunPun checkout

```sh
./punpun editor install-vscode
```

The local install points VS Code at `editors/vscode`. Reload the editor after installation. Release builds also ship a versioned `.vsix` that can be installed with VS Code's **Install from VSIX** command.

## Compiler commands

- **PunPun: Build Current File**
- **PunPun: Run Current File**
- **PunPun: Check Current File**
- **PunPun: Build Windows x86-64 .exe**
- **PunPun: Format Current File**
- **PunPun: Run Project Tests**
- **PunPun: Restart Language Server**

The extension first checks configured paths, then workspace-local PunPun launchers, then normal `PATH` discovery. `punpun.toolPath`, `punpun.compilerPath`, and `punpun.languageServerPath` can pin explicit tools when needed.

## Language identity

- language id: `punpun`
- grammar scope: `source.punpun`
- source extension: `.pp`

The extension icon and `.pp` file icons are generated by `scripts/build_brand.py`; they should not be edited by hand.
