Publish your own package

From Punpun.toml to an immutable PPX release

PPX validates locally first, then the registry validates the uploaded archive again. Two checks are cheaper than one poisoned package ecosystem.

1. Add package metadata

[package]
name = "my_math"
version = "1.2.0"
description = "Small math helpers"
license = "MIT"
readme = "README.md"
keywords = ["math", "helpers"]
entry = "src/main.pp"

[dependencies]
json = "^0.1.0"

2. Validate without uploading

ppx publish --dry-run

This prints package identity, archive size, SHA-256, and dependency requirements. Path-only dependencies are rejected for registry publication.

3. Register, log in, publish

ppx register developer
ppx login developer
ppx publish

ppx upload runs the same publication path. Published versions are immutable; bump the version for a new release.

4. Install or download

ppx install my_math '^1.2.0'
ppx download my_math 1.2.0 -o my_math-1.2.0.zip

Both install and download verify the registry checksum before accepting package bytes.

PPX {{VERSION}}Package source is never executed during publication.
