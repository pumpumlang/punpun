Trust the package, not the network

Registry security

PPX treats package contents and network responses as untrusted input.

Protections in this beta

  • SHA-256 verification before downloaded packages enter the local cache.
  • Archive traversal rejection and upload/expanded-size limits.
  • Immutable published versions with explicit, reversible yanking.
  • Hashed API tokens and authenticated publication endpoints.
  • No execution of uploaded package source during publication.

Honest beta boundary

The server bundled in the source tree is a development reference implementation. Public hosting, provenance signing, abuse moderation, organizational accounts, rate limiting and disaster-recovery operations remain production work.
