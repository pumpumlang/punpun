Registry security

The beta backend validates package names, authenticates publication, rejects archive traversal, enforces upload and expanded-size limits, stores token hashes rather than raw API tokens, verifies SHA-256 package integrity, and never executes uploaded package source during publication.

Beta limitations

The bundled registry is a local-development reference server. It does not claim production deployment hardening, federation, provenance signing, abuse moderation, or hosted availability.
