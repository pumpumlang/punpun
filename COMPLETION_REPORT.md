# PunPun 1.0 completion report

PunPun `1.0.0` completes the stable language-contract milestone on Linux x86-64. The 1.x line now has enforceable source/API stability, ABI/runtime/package/lockfile epochs, platform support tiers, reproducible release metadata and optional Ed25519 signatures. `make test` includes the 1.0 stability, ABI, platform-policy and signing regression suite. Platform qualification remains based on observed real workflows.
