# PunPun publish cleanup rules.
#
# Sections:
#   [remove-dirs]   directory names / repo-relative paths deleted whole
#   [remove-files]  file names / repo-relative globs deleted
#   [protect]       wins over every remove rule above
#   [stale]         only removed when --include-stale is passed
#
# A rule containing "/" is matched against the repo-relative path.
# A rule without "/" is matched against the basename anywhere in the tree.
