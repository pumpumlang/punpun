# E0201: unknown name

PunPun could not resolve an identifier in the current lexical/module scope.

Common causes:

- a misspelled local, parameter, function, type, or imported symbol;
- a missing `bring`/`import` declaration;
- a name used outside the scope where it was declared.

PunPun compares unresolved names with visible symbols and may offer a `did you
mean` fix when the edit distance is small. The same E0201 diagnostic is used by
`pp check` and the language server.

```punpun
launch {
    let player = 1;
    say(playre); // E0201, suggests `player`
}
```
