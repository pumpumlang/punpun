# PunPun 1.3

PunPun 1.3 promotes PPC to the canonical compiler and keeps the stable 1.0
language/ABI contract.

Highlights:

- shared semantic frontend with C, native x86-64, and bytecode backends;
- compiler-native LSP and simplified VS Code client;
- verified HTTPS builtins, `std.net.https`, and the `https` package;
- Win32/X11 native GUI builtins and `std.gui`;
- expanded standard library and all-backend regression suite;
- release, version, ABI, documentation, and package tooling moved to the new layout.

HTTPS loads the system libcurl and always enables peer/hostname verification.
GUI support is availability-based and remains usable on headless systems.

Linux x86-64 is validated locally. Windows and Arch qualification is determined
by their actual release workflows, not inferred from Linux.
