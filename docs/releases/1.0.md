# PunPun 1.0

PunPun 1.0 is the first stable compatibility line. It freezes language/runtime ABI epoch 1, package/lockfile format 1, and a machine-enforced public language/stdlib baseline. It adds `pp stable-check`, `pp platform-info`, Ed25519-capable release/PPX verification, source SBOM/provenance generation, and explicit platform support tiers.
